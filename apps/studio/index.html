Complétion et services de langage

La complétion PHP et les diagnostics HTML utilisent des services WASM séparés. Les erreurs de syntaxe PHP sont signalées par l’éditeur ; les diagnostics sémantiques PHP complets restent à intégrer. JavaScript utilise SWC et les types jQuery internes. Ctrl+Espace : compléter · Ctrl+F : rechercher · Échap puis Tab : quitter l’éditeur. La bibliothèque jQuery doit être chargée par votre site pour s’exécuter.

Cycle de vie des outils

Décharger conserve le brouillon et retire l’interface de l’outil. Le moteur continue de servir les clients.

PHP seul, puis SQL au besoin

La première connexion PDO MySQL ou MySQLi active MariaDB. Elle reste active jusqu’à la sauvegarde ou la fermeture. Après arrêt, le studio crée un nouveau moteur ; il ne rejoue pas les requêtes PHP.
