Sessions

Une session est un visiteur : ses cookies, sa session PHP. Deux fenêtres de la même session partagent leur connexion ; deux sessions se comportent comme deux personnes. Ouvrez-les aussi depuis l’éditeur, avec le bouton ▶ Aperçu.
